# Componentes de Elementos

## Componentes de Gestión de Empleados

### CreateEmployee.jsx
Componente para la creación de nuevos empleados.
- Formulario completo para ingresar datos de empleados
- Validación de campos
- Integración con el backend

### EditEmployee.jsx
Componente para la edición de empleados existentes.
- Formulario pre-poblado con datos del empleado
- Actualización de información
- Validación de campos

### InfoEmployeTable.jsx
Tabla de visualización de empleados.
- Muestra lista de empleados
- Ordenamiento de columnas
- Acciones rápidas (editar, eliminar)

### EmployeeCSV.jsx
Componente para importación de datos mediante CSV.
- Carga de archivos CSV
- Validación de formato
- Procesamiento de datos

### DeleteEmployeeModal.jsx
Modal de confirmación para eliminar empleados.
- Confirmación de eliminación
- Manejo de errores
- Feedback visual

## Componentes de Asistencia

### RegistroAsistencia.jsx

### AsistenciaMensualGrafico.jsx
Gráfico de asistencia mensual.
- Visualización de datos
- Filtros por período
- Exportación de datos

### AsistenciaInasistenciaGrafico.jsx
Gráfico de asistencia vs inasistencia.
- Comparativa de datos
- Visualización temporal
- Análisis de tendencias
